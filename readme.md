# when
- from `2026 April 1` to `2026 April 29`

# what
- a science project to learn how to use AI and research what Codex 5.4 can do

# scope
- as a toy project I picked to implement the AV1 video encoder/decoder based on the specs at https://aomediacodec.github.io/av1-spec/av1-spec.pdf

# outcome
- all the 22 test AV1 videos from public sources are playing with varying degree of success
- I did not write a single line of code, even if I can, I did not do it on principle
- the 5.4 was similar failure like the Gemini, when I was about to pull the plug because of 3 weeks straight of failures, OpenAI released 5.5, I did not switch immediately to keep the fairness but and at and as a last ditch effort to see if anything new came out, I switched to it and that was a radical upgrade in quality and made all the videos play, it fixed all the bugs, etc

# timeline
- started on Pro plan from the start, ~ $100
- as of today - 2026 April 08 - total time it took to implement pure Go version of the AV1 decoder was 3 weeks of 24/7 Codex 5.4 failing badly and almost a week of Codex 5.5 fixing everything
